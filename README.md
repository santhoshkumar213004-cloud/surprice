# Birthday Surprise ❤️

A cinematic romantic birthday website built with React + Vite + TypeScript.

## Run

```bash
npm install
npm run dev
```

Build check:

```bash
npm run build
```

## Personalize

Edit:

`src/data/birthdayData.ts`

You can change:
- birthday date
- relationship start date
- hero text
- memories
- timeline
- love letter
- reasons
- final message

## Photos

Replace the placeholder files in:

`public/images/`

## Music

Add your own file:

`public/audio/romantic.mp3`

Music never autoplayes; the visitor chooses to turn it on.
